Travel Planner App

Overview

The Travel Planner App is a modern and intuitive mobile application designed to make travel planning easy and convenient. It allows users to search for places, book flights, and plan trips efficiently using a clean and user-friendly interface.

Features

1. Search Bar with Filter Button

A dynamic search bar where users can search for places.

Includes a filter button for additional customization options.

2. Category Selector

Horizontally scrollable categories for various travel options:

Places: Discover tourist destinations.

Flights: Book flights quickly.

Trains: Find train schedules and book tickets.

Buses: Plan bus travel.

3. Flight Booking Form

Tabs for trip types:

One Way

Round Trip

Multicity

User-friendly fields for:

Choosing departure and arrival locations.

Selecting departure dates with a calendar picker.

4. Responsive Design

Clean and modern UI optimized for mobile devices.

Purple as the primary accent color, creating a vibrant experience.

Technologies Used

Frontend

Jetpack Compose: For building the modern UI.

Kotlin: Primary programming language.

Icons and Resources

Custom icons (e.g., search, filter, flight) from drawable resources.
